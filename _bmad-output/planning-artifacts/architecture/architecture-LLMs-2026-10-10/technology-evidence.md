## Escolha proposta e tradeoffs

Cloudflare Workers + Access + D1 + R2 reúne gateway privado, agendamento e persistência em poucas peças e mantém contratos em JavaScript. Risco: quotas de CPU/subrequests, configuração real de IdP/origens, transação conjunta de controle e provider gráfico. É seed `[ASSUMPTION]`, sem conta/plano/recursos configurados e sem promessa de custo zero.

Vercel Hobby (cron diário) com backend persistente e scheduler externo preserva a mesma UI; [planos de cron](https://vercel.com/docs/cron-jobs/usage-and-pricing) Pro podem suportar maior cadência. Hobby adiciona infraestrutura para atualização de quinze minutos, auth end-to-end e storage. AWS permite jobs/persistência com mais opções, com maior quantidade de configuração para uso de uma pessoa. Rodar só no Mac foi descartado pelo PRD porque atualização para quando ele dorme. Não se escolheu serviço pago por omissão.

Não usar o protótipo como starter de produção: contém ações simuladas, Fontes com proveniência incompleta e divergência entre cópia promovida e `.working`. Preservar como referência exploratória e desenvolver módulos com fixtures próprias. CesiumJS foi escolhido para o renderer do Globo principal: produto sempre 3D, bases MAPA/SAT, terreno, edifícios compatíveis e transição SAT automática para fotorealismo; controles/voos extras por Empresa/região não entram. O app observado é JavaScript ES modules sem Vite/TypeScript instalado. CDN versionada e pacote NPM com assets/workers servidos pela aplicação seguem opções abertas em Q9; qualquer build preserva a instância atual do store. Fazer spike medindo bases, camadas, superfícies, rótulos, WebGL, fallback e ~200 Empresas antes de fixar carregamento/providers.

## Envelope e aceites

- Até 96 janelas de quinze minutos por dia para ações/índices; coleta efetiva respeita pregão de cada mercado. Modelos/notícias têm 24 janelas/dia antes de degradação; não multiplicar API AA por Empresa desnecessariamente.
- Dispatch/retries precisam caber nos limites de cada Fonte e hospedagem. Volume/tamanho das matérias, chamadas LLM e custos não foram medidos; nenhum forecast de US$5 para o produto completo é afirmado.
- Q2 fixa limite de infra/objetos/banco; Q1/Q7 fixam chat/busca/LLM; Q4/Q6 fixam mapas. Default operacional até os aceites é desabilitado para esses serviços.
- Chaves presentes no projeto não foram lidas. Segredos, contas, jobs reais, bundles de produção, auth e browser benchmark não foram inspecionados nem ativados.
